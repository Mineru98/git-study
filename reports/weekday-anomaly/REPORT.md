# 평일·주말 비교와 이상치 탐지

- 기간: 2026-10-01(목) ~ 10-07(수), 7일 (주말 10/3·10/4), 05~23시
- 재현: `.venv/bin/python analysis/weekday_anomaly.py`
- 차트: `daily_and_hourly.png`, `weekend_ratio_and_zscore.png`

## 핵심 수치

| 항목 | 값 |
|---|---|
| 평일 일평균 하차 | 8,758명 (8,307 ~ 9,058) |
| 주말 일평균 하차 | 5,030명 (토 5,133 / 일 4,926) |
| 주말/평일 비율 (전체) | **0.57** |
| 노선유형별 비율 | 광역 0.54 · 마을 0.56 · 간선 0.59 · 지선 0.60 |
| 노선별 최저 / 최고 | 마을1 **0.48** · 301 0.53 / 201 0.64 · 마을2 0.66 |
| 시간대별 비율 범위 | 0.46(23시) ~ 0.62(14시), 출퇴근 피크(8시·18시) 모양은 주말에도 유지 |
| 평일 일자 변동계수(CV) | 0.07(9001) ~ 0.18(마을2) |
| 이상치 (\|z\| ≥ 3) | 9,709건 중 11건 (0.11%), 모두 주말 과대 방향 |
| 하차 0 레코드 | 14.0% (평일 11.6%, 주말 19.8%, 마을버스 30.2%) |

## 발견

1. **주말 수요는 평일의 약 57%로 균일하게 줄어든다.** 시간대별 비율이 0.46~0.62로 좁게 모여 있어, 주말에 피크가 사라지거나 낮 시간이 늘어나는 패턴은 보이지 않는다.
2. **마을1(0.48)·301(0.53)은 주말 감소폭이 가장 크고**, 마을2(0.66)·201(0.64)은 상대적으로 주말 수요가 유지된다.
3. **평일 일자 변동은 작다(CV ≤ 0.18).** 마을2(0.175)·201(0.125)·마을1(0.122)이 상대적으로 들쭉날쭉하고, 광역 9001(0.068)·301(0.075)은 가장 안정적이다.
4. **뚜렷한 이상치는 없다.** 노선×정류장×시간대별 평일 평균(주말은 노선 주말비율로 보정)을 기대값으로 한 z-score 최대값은 4.8(10/3 토 마을2 법원 21시, 기대 1.1명 → 실제 6명)로, 모두 기대값 1~6명 수준의 소량 구간 변동이다. 평일엔 이상치 0건.
5. **데이터 품질은 양호.** 결측·중복 키·음수 0건, 7일 내내 하차 0인 정류장 없음. 0 하차 비율 14%는 소량 수요 구간(마을버스·심야·주말)에 몰려 있어 구조적 결측보다는 실제 저수요로 보인다.

## 운영 제언

- **주말 감차**: 전체 수요가 평일의 57%이므로 주말 배차를 평일 대비 약 60% 수준(배차간격 약 1.7배)으로 조정해도 재차율은 평일과 비슷하게 유지될 것으로 보인다.
- **우선 대상**: 마을1(주말비율 0.48, 평일 배차 20분·12대)과 광역 301(0.53)부터 감차를 검토한다. 마을2·201은 감축폭을 작게 둔다.
- **피크 유지**: 주말에도 8시·18시 피크가 남아 있으므로 일괄 감차보다 피크 시간대 배차는 덜 줄이는 차등 시간표가 낫다. 23시대(비율 0.46)는 막차 앞당김 후보.
- **모니터링**: 이상치는 소량 구간의 우연 변동이므로 별도 조치는 불필요. 다만 7일(주말 2일) 표본이라 주말 비율은 최소 4주 데이터로 재확인한 뒤 시간표에 반영한다.

## 방법 메모

- 주말비율 = 주말 일평균 하차 / 평일 일평균 하차.
- z = (실제 − 기대값) / max(평일 표준편차, √기대값, 1). 평일 5일 표본의 표준편차가 불안정해 포아송 근사로 하한을 뒀다.
- IQR(평일 분포, 3×IQR) 기준은 교차 확인용으로만 사용. 평일 5개 점으로 만든 IQR이 좁아 소량 구간에서 과다 검출(159건)되므로 판단은 z-score 기준으로 했다.
