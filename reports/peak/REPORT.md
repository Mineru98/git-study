# 시간대별 수요·출퇴근 피크 분석

- 데이터: 2026-10-01 ~ 10-07 (평일 5일, 주말 10/3·10/4), 05~23시, 노선 8개 하차인원
- 실행: `.venv/bin/python analysis/peak_analysis.py`
- 차트: `hourly_weekday_weekend.png`, `hourly_by_route_type.png`

## 핵심 수치

| 항목 | 값 |
|---|---|
| 평일 출근 피크 | **8시** 1,023명/일 (전체 시간 평균 461명의 2.2배) |
| 평일 퇴근 피크 | **18시** 1,020명/일 |
| 피크 집중도 (8시+18시 / 일 하차) | 평일 23.3%, 주말 23.6% (19개 시간대 중 2개가 약 1/4) |
| 피크 3시간대 (7~9시, 17~19시) 비중 | 7일 합계 기준 55.0% |
| 하루 평균 하차 | 평일 8,758명 / 주말 5,030명 (주말 = 평일의 57%) |
| 낮 시간 최저 (평일) | 11시 312명, 14시 316명 (피크의 약 30%) |

## 발견

1. **쌍봉형 수요.** 평일 8시와 18시에 하차가 거의 같은 크기(약 1,020명)로 몰리고, 7·9시와 17·19시가 그 뒤를 받친다. 12시에 작은 점심 봉우리(414명)가 있다.
2. **노선유형 간 차이가 작다.** 4개 유형 모두 피크는 8시·18시다. 피크 2시간 비중은 광역 24.0%로 가장 높고 마을 21.9%로 가장 낮다. 마을버스는 19시 비중(8.6%)이 다른 유형(7.4~7.8%)보다 높아 퇴근 수요가 한 시간 늦게까지 이어진다.
3. **주말도 시간대 모양은 평일과 같다.** 주말은 총량만 57% 수준으로 줄고, 시간대별 비중 차이는 모두 ±0.4%p 이내다. 실제 데이터라면 주말 출퇴근 피크가 약해져야 하므로, 이 결과는 더미 데이터 생성 규칙(평일·주말에 같은 시간 가중치를 쓰고 총량만 줄임) 때문으로 보인다.

## 운영 제언

- **7~9시, 17~19시 증차.** 이 6시간에 하차의 55%가 몰린다. 배차간격이 긴 광역 9001(30분)·301(20분)부터 피크 시간에 간격을 줄인다.
- **10~15시 감차.** 평일 낮 수요는 피크의 30~40% 수준이다. 이 시간대 차량을 피크로 옮기면 운행대수를 늘리지 않고도 대응할 수 있다.
- **마을버스는 퇴근 증차를 19시까지 연장.**
- **주말은 전 시간대 약 55~60% 수준으로 균등 감축.** 다만 주말 패턴은 실제 데이터로 다시 확인한 뒤 적용해야 한다.
